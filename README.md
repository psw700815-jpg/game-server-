# game-server-
# 🎮 로컬 협동 탑다운 슈터

2~4명의 플레이어가 함께 적의 공격을 막아내는 **로컬 협동(Co-op) 탑다운 슈팅 게임**입니다.  
동료 부활, 자원 공유, 역할 분담을 통해 혼자보다 함께할 때 더 강해지는 플레이를 목표로 합니다.

## 📌 핵심 컨셉

| 항목 | 내용 |
| --- | --- |
| 장르 | 탑다운 슈팅 |
| 플레이 인원 | 2~4명 |
| 플레이 방식 | 로컬 협동 플레이(Co-op) |
| 핵심 요소 | 웨이브 생존, 기지 방어, 팀워크 |

## 🎯 공유 목표

플레이어들은 팀을 이루어 공통의 목표를 달성합니다.

- **웨이브 생존:** 끊임없이 몰려오는 적을 함께 막아내며 생존합니다.
- **코어 및 기지 방어:** 적의 공격으로부터 팀의 공용 코어 또는 기지를 지킵니다.

## 🤝 주요 협동 시스템

### 1. 동료 부활

쓰러진 동료 근처로 이동하여 부활시킬 수 있습니다.  
적을 상대하는 동시에 동료를 구해야 하므로 팀원 간의 협력이 중요합니다.

### 2. 협동 콤보 보너스

여러 플레이어가 같은 적을 함께 공격하여 처치하면 추가 점수 또는 아이템 드롭 보너스를 획득합니다.  
팀원들이 공격 대상을 맞추고 협력하도록 유도합니다.

### 3. 자원 공유

획득한 파워업을 혼자 사용할지, 팀 전체에 나눌지 선택할 수 있습니다.  
개인의 전투력 강화와 팀 전체의 생존 사이에서 전략적인 판단이 필요합니다.

| 파워업 | 효과 |
| --- | --- |
| `MultiShot` | 다중 발사 |
| `Shield` | 보호막 |
| `Heal` | 체력 회복 |

### 4. 캐릭터별 역할 분화

캐릭터마다 다른 무기와 스킬을 사용하여 팀 내 역할을 나눕니다.

| 역할 | 주요 특징 |
| --- | --- |
| 탱커형 | 적의 공격을 받아내며 동료를 보호 |
| 딜러형 | 높은 공격력으로 적을 빠르게 처치 |
| 힐러형 | 체력 회복과 지원으로 팀의 생존 유지 |

## 🌐 게임 서버의 주요 역할

게임에서 발생하는 상황과 각 상황에서 서버가 처리해야 할 작업을 정리한 표입니다.

| 게임에서 벌어지는 일 | 서버가 해야 할 일 |
| --- | --- |
| 🎮 **게임을 켰다** | 서버 접속 요청 수신 → 사용자 인증(누구인지 확인) → 방/세션 목록 응답 |
| 👥 **친구랑 같이 하고 싶다** | 방(룸) 생성 및 입장 처리 → 참가자 목록 관리 → 같은 방의 모든 플레이어에게 입장 사실 알림(브로드캐스트) |
| 🏃 **캐릭터를 움직였다** | 클라이언트가 보낸 입력(방향키 등) 수신 → 이동 가능 여부 검증(벽 뚫기 등 방지) → 새 좌표 계산 → 같은 세션의 다른 클라이언트에게 좌표 전송 |
| 🎁 **아이템을 먹었다** | 클라이언트의 아이템 획득 요청 수신 → 해당 위치에 아이템이 있는지 및 획득 가능한지 검증 → 획득 처리 → 모든 참가자에게 아이템 제거 알림 → 인벤토리/점수 갱신 |
| 🏁 **게임이 끝났다** | 승패 및 점수 판정 → 모든 참가자에게 결과 전송 → 세션 종료 및 리소스 정리(방 삭제 등) |
| 🔄 **다시 접속했다** | 사용자 재인증 → 기존 세션 및 참가 정보 확인 → 복귀 가능한 경우 세션 재연결 및 현재 게임 상태 동기화 → 복귀할 수 없는 경우 로비로 안내 |

> **참고:** 재접속 처리 흐름은 예시이며, 프로젝트의 재접속 정책에 맞게 조정할 예정입니다.



번호	패킷 이름	역할 및 전달 정보	서버가 확인하고 처리할 내용
1	C2S_LOGIN_REQUEST
로그인 요청	로그인 아이디와 비밀번호를 전달합니다.	계정 정보를 검증하고, 성공하면 해당 연결을 로그인한 사용자와 연결합니다.
2	C2S_ROOM_REQUEST
방 관리 요청	방 목록 조회, 방 생성·입장·퇴장, 역할 선택, 준비·시작을 요청합니다. 요청 종류, 방 번호, 선택 역할, 준비 여부 등을 전달합니다.	로그인 여부, 방 존재 여부, 정원, 참가 상태, 게임 시작 권한과 조건 등을 확인합니다.
3	C2S_MOVE_REQUEST
이동 요청	캐릭터의 이동을 요청합니다. 입력 순번과 이동 방향을 전달합니다.	이동 가능한 상태인지 확인하고, 이동 속도와 벽 충돌을 적용하여 실제 위치를 계산합니다.
4	C2S_ATTACK_REQUEST
공격 요청	일반 무기 공격을 요청합니다. 요청 번호, 무기 번호, 조준 방향을 전달합니다.	무기 보유 여부, 탄약, 공격 간격, 공격 가능한 상태를 확인하고 투사체 생성이나 명중·피해를 처리합니다.
5	C2S_SKILL_REQUEST
스킬 사용 요청	캐릭터의 고유 스킬 사용을 요청합니다. 요청 번호, 스킬 번호, 대상 또는 사용 방향을 전달합니다.	해당 캐릭터가 가진 스킬인지, 재사용 대기시간과 사용 자원, 대상 조건이 맞는지 확인한 뒤 효과를 적용합니다.
6	C2S_ITEM_PICKUP_REQUEST
아이템 획득 요청	바닥에 있는 아이템을 획득하고 싶다는 요청입니다. 요청 번호와 아이템 번호를 전달합니다.	아이템이 실제로 존재하는지, 올바른 대상인지, 획득 거리 안인지, 이미 다른 사람이 획득하지 않았는지 등을 확인하고 처리합니다.
7	C2S_ITEM_USE_REQUEST
아이템 사용·공유 요청	보유한 파워업을 자신 또는 팀에 사용하도록 요청합니다. **요청 번호, 보유 아이템 번호, 사용 방식인 SELF 또는 TEAM**을 전달합니다.	아이템 보유 여부, 현재 사용 가능 여부, 팀 공유 가능 여부와 적용 대상을 확인한 뒤 아이템을 소모하고 효과를 적용합니다.
8	C2S_REVIVE_REQUEST
동료 부활 요청	쓰러진 동료의 부활을 시작하거나 취소하도록 요청합니다. **요청 번호, 대상 플레이어 번호, START 또는 CANCEL**을 전달합니다.	대상의 존재 여부, 같은 팀인지, 쓰러진 상태인지, 요청자가 부활 가능한 상태인지, 거리가 적절한지 검증합니다. 부활 시간이 필요하다면 조건을 유지했는지 확인한 뒤 완료합니다.

여기서 이동 요청에는 “이동하려는 방향”을 보내고, 공격 요청에는 “공격하려는 방향”을 보내도록 정한 거야. 최종 위치나 피해량을 클라이언트가 확정해서 보내는 구조는 아니야.

2. 서버 → 클라이언트 패킷 8종

서버가 검증·처리한 결과와 현재 게임 상황을 알려주는 패킷이야.

번호	패킷 이름	역할 및 전달 정보	전송 대상
1	S2C_LOGIN_RESULT
로그인 결과	로그인 성공·실패를 알려줍니다. 결과 코드, 성공 시 사용자 번호와 닉네임을 전달합니다.	로그인을 요청한 클라이언트만
2	S2C_ROOM_UPDATE
방 정보·처리 결과	방 관리 요청의 결과와 변경된 방 정보를 알려줍니다. 요청 번호, 결과 코드, 방 목록 또는 방 정보, 참가자 목록, 역할, 준비 상태, 게임 시작 여부 등을 전달합니다.	요청 결과는 요청자, 방 상태 변경은 같은 방의 모든 클라이언트
3	S2C_WORLD_STATE
게임 상태 동기화	서버가 관리하는 현재 게임 상태를 전달합니다. 서버 갱신 순번, 플레이어·적·투사체·아이템 상태, 코어 체력, 현재 웨이브 등이 포함됩니다.	같은 방의 모든 클라이언트
4	S2C_COMBAT_EVENT
전투 사건·처리 결과	공격과 스킬 사용, 피격, 적 처치, 협동 콤보 등을 알려줍니다. 사건에 따라 행동한 플레이어, 대상, 공격·스킬 종류, 피해·회복량, 콤보 보상, 결과 코드 등을 전달합니다.	공유할 전투 사건은 같은 방 전체, 요청 실패는 요청자
5	S2C_ITEM_PICKUP_RESULT
아이템 획득 결과	아이템 획득 성공·실패를 알려줍니다. 요청 번호, 결과 코드, 아이템 번호, 획득한 플레이어 번호를 전달합니다. 성공하면 해당 아이템이 사라졌다는 것을 함께 알립니다.	획득 성공은 같은 방 전체, 실패는 요청자
6	S2C_ITEM_USE_RESULT
아이템 사용·공유 결과	파워업 사용 결과를 알려줍니다. 요청 번호, 결과 코드, 아이템 종류, 개인·팀 사용 구분, 효과가 적용된 대상과 효과 정보를 전달합니다.	사용 성공은 같은 방 전체, 실패는 요청자
7	S2C_REVIVE_EVENT
부활 진행·결과 알림	동료 부활의 시작·취소·완료 또는 요청 실패를 알려줍니다. 부활 단계, 요청자와 대상 번호, 남은 시간, 완료 시 체력, 결과 코드 등을 전달합니다.	부활 상태 변경은 같은 방 전체, 요청 실패는 요청자
8	S2C_GAME_RESULT
게임 종료 결과	게임 종료와 최종 기록을 알려줍니다. 승패, 종료 사유, 최종 점수, 도달 웨이브, 생존 시간을 전달합니다.	같은 방의 모든 클라이언트
